## C major (C)

Three fingers in a diagonal line, from the 5th string at the 3rd fret down to the 2nd string at the 1st fret. Strum from the 5th string.

::build C

## Watch out for

- The **index finger** muting the open 1st string: curl it.
- The **ring finger** not pressing the 5th string firmly: that's the root note of the chord, so it needs to sound.
- Strumming the low E: start on the 5th.

::listen C

::trouble muted-strings wrong-strings buzzing
